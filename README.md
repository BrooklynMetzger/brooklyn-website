Brooklyn Metzger (Developer Portfolio / Personal Website)
This repository contains the source code for my personal developer portfolio. The website uses a Windows XP-inspired desktop interface to showcase my projects and source code.

Live website
https://brooklynmetzger.github.io/brooklyn-website/

Features
Interactive Windows XP-inspired interface
Desktop shortcuts, Start menu, taskbar, and live clock
Projects browser
Live repository file trees loaded from GitHub
Source code viewer 
Technologies Used
React
TypeScript
Vite
Tailwind CSS
GitHub REST API
GitHub Actions
GitHub Pages

To Run locally:

pnpm install
Start the development server:

pnpm dev
Create a production build:

pnpm build
The production files are generated in the dist directory.

Projects
The portfolio includes links to several of my projects, if the project is collaborative I specifically explain which portion I worked on,
otherwise it is my own creation.
